Builds the whole site of the Perla theme in one click: pages, menu, sample articles and the front page.

== Description ==

Perla Starter is the companion of the Perla block theme. The theme comes with ready-made pages as patterns; this plugin turns them into real pages for you.

One click on Appearance > Perla Starter creates:

* Home, About, Team, Reviews, Treatments with its six treatment pages, Prices, First visit, Questions, Journal, Contact and Terms
* a menu with those pages, unless you have already made one
* three sample articles, if you want them
* copies of the theme photographs in the Media Library, so they can be replaced like any other image

It then sets Home as the front page and Journal as the page for the articles.

Every page is made of ordinary blocks: open it and edit it like any other page.

Nothing you already have is overwritten. If a page with the same address exists, it is kept as it is. A second click never creates duplicates.

Changed your mind? "Remove what the starter created" moves those pages, articles and the menu to the trash and puts the homepage settings back.

The plugin needs the Perla theme to be active. It makes no connection to other sites and collects no data.

== Installation ==

1. Install and activate the Perla theme.
2. Install and activate Perla Starter.
3. Go to Appearance > Perla Starter and click "Build the site".

Once the site is built you can deactivate and delete the plugin: the pages stay.

== Frequently Asked Questions ==

= Will it overwrite my pages? =

No. A page is created only if no page has that address yet. The screen shows which pages exist and which will be created before you click.

= Can I undo it? =

Yes. The same screen has a button that moves everything the starter created to the trash and restores the homepage settings. The photographs stay in the Media Library.

= Does it work with other themes? =

No. The pages are built from the patterns of the Perla theme.

= Can I delete the plugin afterwards? =

Yes. The pages, the menu and the articles are ordinary WordPress content and stay where they are.
