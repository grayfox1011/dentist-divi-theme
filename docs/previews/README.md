# Anteprime

Schermate di tutti i layout, catturate nel Visual Builder di Divi 5.4.0 con i file di questo
repository.

| File | Contenuto |
| --- | --- |
| `overview.jpg` | Colpo d'occhio: home su desktop e telefono, più tre pagine interne. |
| `home-desktop.jpg`, `home-tablet.jpg`, `home-mobile.jpg` | La home alle tre larghezze. |
| `about-`, `services-`, `service-detail-`, `blog-`, `contact-desktop.jpg` | Le pagine interne. |
| `header-footer-desktop.jpg`, `blog-post-desktop.jpg`, `404-desktop.jpg` | I template del Theme Builder. |
| `contact-mobile.jpg` | Modulo e mappa su telefono. |

Due avvertenze:

- Le immagini sono i segnaposto inclusi nei layout, non foto.
- Le card del blog e il template dell'articolo mostrano gli articoli del sito su cui è stata
  fatta la cattura (la demo pubblica di Elegant Themes). Sul sito dell'acquirente compaiono i
  suoi articoli. Per questo motivo queste due schermate non vanno usate nell'inserzione.
