# Anteprime

Schermate del sito demo reale: WordPress con Divi 5.15.1 e il child theme di questo repository,
così come lo installa il tema quando viene attivato.

| File | Contenuto |
| --- | --- |
| `overview.jpg` | Colpo d'occhio: home su desktop e telefono, più tre pagine interne. |
| `home-desktop.jpg`, `home-tablet.jpg`, `home-mobile.jpg` | La home alle tre larghezze. |
| `about-`, `services-`, `service-detail-`, `blog-`, `contact-desktop.jpg` | Le pagine interne (`service-detail` è la pagina Dental Implants, con i prezzi). |
| `service-pages.jpg` | La parte alta delle sei pagine servizio. |
| `setup-screen.jpg` | La schermata "Perla Setup" dopo l'installazione automatica. |
| `animations.mp4`, `animations.gif` | Le animazioni della home: ingresso della hero, hero che si rimpicciolisce, sezioni che entrano. Il video dura 13,5 secondi ed è senza audio, pensato per l'inserzione Etsy. |
| `blog-post-desktop.jpg`, `404-desktop.jpg` | I template del Theme Builder. |
| `contact-mobile.jpg` | Modulo e mappa su telefono. |

Le immagini sono i segnaposto inclusi nei layout, non foto: per l'inserzione vanno sostituite.

Il video è ripreso fotogramma per fotogramma con l'orologio del browser sotto controllo, quindi
mostra i tempi reali delle animazioni ma non dice nulla sulla fluidità su un dispositivo vero.
Le immagini ferme sono riprese con le animazioni spente, quindi mostrano le pagine nel loro
stato finale.
